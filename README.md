# Вишлист Ронни Макса на Новый год

Страница-письмо со сбором на коронку: https://ronnimaks.github.io/wishlist/

- `index.html` - вся страница (анимация, шкала, кнопка на сбор Т-Банка).
- `data.json` - собранная сумма. Её обновляет робот `.github/workflows/update.yml` раз в ~5 минут.
- `ronni.jpg` - фото-марка, `og.jpg` - превью ссылки, `og.html` - из чего сделано превью.
- Проверить без денег: `?demo=20000` в конце адреса.
